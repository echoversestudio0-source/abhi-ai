ABHI AI - GitHub e Publish korar niyom
================================
1. github.com e giye New Repository banau - nam dau: abhi-ai
   Public rakho, Add README tick dau.
2. Upload files e click kore ei file ta dau: ABHI-AI-index.html
   Kintu upload er por rename kore dau: index.html
3. Settings > Pages > Branch: main > Folder: / (root) > Save
4. 1-2 min por tor link peye jabi:
   https://TOMAR-USERNAME.github.io/abhi-ai/
5. Erpor theke kono change lagle ekhane amake chat e bolo -
   "ABHI AI te omuk change koro" - ami notun code diye debo,
   tumi sudhu GitHub e file ta replace kore debe. Bas!
Alternative: Netlify.com e giye file ta drag-drop korleo live hoye jabe.
